# Recursos visuales de la documentación

Esta carpeta se reserva para capturas y GIFs grabados de una compilación
real de Unísono. No se incluyen imágenes simuladas como si fueran
funcionalidades comprobadas.

## Plan de capturas y GIFs pendientes

| Archivo sugerido | Qué grabar | Requisitos de la toma |
|---|---|---|
| `inicio-repertorio.png` | Inicio y listado de canciones de un equipo de prueba | Ocultar nombres, fotos, correos y cualquier dato de una iglesia real. |
| `letra-acordes.gif` | Abrir una canción, cambiar tono y alternar la vista con acordes | Usar una canción de demostración propia o con permiso de uso. |
| `armar-setlist.gif` | Crear actividad y ordenar canciones, cantante y tono asignado | Datos ficticios; no mostrar códigos de invitación reales. |
| `modo-en-vivo.gif` | Líder cambia canción/sección mientras otro teléfono la sigue | Solo grabar después de validar en al menos dos teléfonos reales; indicar si había internet. |
| `sin-internet-2-dispositivos.gif` | Preparar caché, desconectar internet y probar Nearby | Grabar radios locales habilitadas; documentar modelo/OS y el resultado en el issue #14. |
| `perfil-equipo.png` | Perfil, miembros y preferencias de lectura | Cuenta y datos de prueba. |

Cuando exista un recurso, agrégalo aquí y enlázalo desde `README.md` con
una descripción alternativa. Mantén los nombres y contenido libres de
credenciales, códigos de equipo reales, información personal y letras
protegidas sin autorización.
